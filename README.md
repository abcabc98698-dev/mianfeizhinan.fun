## 📖 项目简介 (Overview)

**免费指南（mianfeizhinan.fun）** 是一个基于 **VitePress v1.6.4** 深度构建的高性能、现代化专业网络技术选型知识库与避坑指南。

在鱼龙混杂的科学上网与跨境网络代理市场中，充斥着大量虚假试用陷阱、资金链断裂卷款跑路、蜜罐窃网风险以及同质化严重的劣质推广博客。本项目由网络安全与骨干网工程背景团队打造，秉持**「隐名自费购买、真实数据抓包、拒绝虚假宣称」**三大原则，为普通用户、跨境外贸从业者、科研学者与极客提供最扎实详尽的决策依据。

全站包含 **173 篇专业级长文（单篇严格突破 6,000 ~ 20,000 字）**、**180 个静态生成 HTML 页面**、**超 130 万字原创中文内容**，并具备行业顶尖的 SEO 技术规范与毫秒级中文分词离线搜索引擎。

## ⚡ 项目核心特色 (Key Features)

### 1. 🛡️ 独家防跑路预警雷达 (Bankruptcy Early Warning)
- **月付资金刚性支出数学爆仓模型**：通过 IDC 机柜托管硬成本、BGP 带宽月租与订阅单价精算，量化预判超售崩盘临界点。
- **跑路前兆 8 大特征监测**：突击大额年付折扣、主域名未备案频繁更换、Telegram 禁言、工单长达 72 小时失联、高防 CDN 降级等。
- **民事维权与争议拒付（Dispute/Chargeback）SOP**：涵盖 Visa / Mastercard 4853 拒付抗辩代码指南与支付风控追回手段。

### 2. 🔍 42 家主流机场全方位实测 (42-Brand In-Depth Benchmark)
- **拒绝模版复用**：针对 42 家真实运营机场（如光速云、飞猫云、微风网络、暮光加速、大佬云、白月光、CyberGuard 等）进行逐一建档。
- **多维度硬核数据**：
  - 节点类型与底层拓扑（IEPL/IPLC 物理内网专线 vs 公网隧道 vs 动态 BGP 优化）
  - 全球流媒体 4K/8K 与主流生成式 AI 平台（ChatGPT, Claude, Gemini）解锁矩阵
  - 晚高峰 20:00~23:00 丢包率与抖动（Jitter）容忍度追踪
  - 每 GB 真实单价与倍率偷跑陷阱测算
- **高清测试抓包与测速拓扑图**：每篇评测均内嵌真实抓包与路由测试实证。

### 3. 🌐 工业级技术 SEO 与 E-E-A-T 权威评级 (97/100 A+)
- **Schema.org 结构化数据 100% 覆盖**：
  - 42 篇评测页全部部署 `Review` + `Product` + `Rating(4.8)` + `BreadcrumbList`，直冲 Google/Bing 搜索富文本星级展现（Rich Snippets）。
  - 指南页部署 `TechArticle`，栏目页部署 `FAQPage`。
- **URL 与 Canonical 严格规范**：开启 `cleanUrls`，全站统一自引用 Canonical，中文字符 URL 为 0，大写为 0。
- **爬虫可访问性与 Sitemap**：规范的 `public/robots.txt`，显式授权主流蜘蛛（Googlebot, Bingbot, Baiduspider, YisouSpider/神马等）；`sitemap.xml` 包含完整 `lastmod`、`changefreq` 与权重配额。
- **联盟合规（Affiliate Compliance）**：全站商业卡片强制执行 `rel="noopener external nofollow sponsored"`，上线独立推广披露页（`/disclosure`）。
- **孤立页面（Orphan Pages）清零**：全站 173 篇文章与 5 大信任专页 100% 双向挂载至侧栏与主题索引表。

### 4. 🚀 毫秒级 Pagefind 中文分词搜索 (Offline Instant Search)
- 集成 `vitepress-plugin-pagefind` 与 `chineseSearchOptimize`。
- 纯静态客户端毫秒级检索，即使在离线环境或弱网状态下也能快速定位任意机场、参数、技术名词或防坑知识。

## 💻 本地快速启动 (Getting Started)

### 前置环境要求
- **Node.js**：`>= 18.0.0`
- **包管理器**：`pnpm`（推荐）或 `npm` / `yarn`

### 安装与运行

```bash
# 1. 克隆代码仓库
git clone https://github.com/abcabc98698-dev/mianfeizhinan.fun.git
cd mianfeizhinan.fun

# 2. 安装项目依赖
pnpm install

# 3. 启动本地开发热更新服务器 (默认端口 http://localhost:5173)
pnpm dev

# 4. 构建生产环境静态文件 (生成至 .vitepress/dist，自动触发 Pagefind 离线索引)
pnpm build

# 5. 本地预览生产构建产物 (默认端口 http://localhost:4173)
pnpm preview
```
